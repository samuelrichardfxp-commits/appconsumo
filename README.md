# EcoQuiz — Sustentabilidade vs. Consumo

Jogo educativo de perguntas e respostas para aprender sobre sustentabilidade, consumo consciente, reciclagem, meio ambiente e lixo eletrônico.

## Executar localmente

```sh
npm install
npm run dev
```

## Verificações

```sh
npm test
npm run build
```

O quiz tem 20 perguntas distribuídas em cinco fases. Cada resposta correta soma 100 pontos; ao final, o jogador vê sua classificação e pode revisar todas as respostas.
